# Kotlin Holdem
Kotlin implementation of Texas holdem

## Run
You can run cli version of game using
```bash
./gradlew run
```
Or GUI version:
```bash
./gradlew runGui
```
Or build JVM console app and run:
```bash
./gradlew installDist
./build/install/spbu-kotlin-holdem/bin/spbu-kotlin-holdem
```
## Test
To run tests, use
```bash
./gradlew test
```
